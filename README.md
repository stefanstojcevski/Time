# TIME Coffee Bar - Digital Menu

This is the digital menu for TIME Coffee Bar, a cafe in Resen, Macedonia.

It's not just a demo project - the cafe actually uses this every day to show their menu to customers, and so far it's working out great.

## What it does

- Search through drinks and food in real time
- Browse by category
- Switch between Macedonian and English
- Works well on phones, since most people pull it up on their own device at the table

## Built with

Plain HTML, CSS and JavaScript, no frameworks. Menu items are stored in `menu.json`, so updating the menu is just a matter of editing that file.
